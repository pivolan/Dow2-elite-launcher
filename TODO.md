## Обновление лаунчера (с 1.3.0)

Лаунчер обновляет сам себя тем же движком, что и Elite: качает с наших серверов только изменённые куски файлов и ставит новую версию по кнопке игрока. GitHub нужен только для сборки (Actions).

**Путь новой версии**

1. Разработчик пишет `changelog/<версия>/<язык>.md`, поднимает версию и вручную запускает сборку на `main`.
2. CI собирает Windows, Linux и macOS; exe для Windows подписывает SignPath.
3. CI публикует файлы лаунчера в папку `update/` как версии `launcher-<версия>-windows` и `launcher-<версия>-linux` (`elite-publish version`: манифест и `blobs/`). Рядом пишет `update.json` (номер версии, заметки из `changelog/` на 5 языках, имя манифеста для каждой ОС) и `news.json` (заметки последних релизов для блока новостей). Всё подписано ключом лаунчера.
4. Деплой (`rsync`) кладёт установщики и папку `update/` в папку загрузок на сервере.
5. Лаунчер при старте и раз в 15 минут, вместе с `launcher.json`, читает `update/update.json` по адресам из `launcher.json` (`launcher_update.store`) и проверяет подпись. Если версия новее, в шапке появляется «Вышел Elite Launcher vX — Обновить».
6. По кнопке движок докачивает в папку лаунчера недостающие куски и сверяет SHA-256. Работающий exe переименовывает в `*.old` и кладёт на его место новый, затем лаунчер перезапускается, а новая версия удаляет `*.old`. Прогресс виден в шапке и полоской внизу. Пока качается Elite, кнопка неактивна.

Без кнопки ничего не ставится, новую версию лаунчер только предлагает.

**Когда сам обновиться не может**, показывает ссылку на страницу загрузки (`launcher_update.urls` в `launcher.json`), как в 1.2.x:
- лаунчер стоит там, куда без прав администратора писать нельзя (Program Files, `.deb` в `/usr`);
- macOS: в 1.3.0 только ссылка;
- лаунчеры 1.2.x обновляются до 1.3.0 один раз вручную, дальше сами.

**Подписи**
- `launcher.json`, версии Elite и дополнений подписаны ключом команды (`keys/public.key`), как раньше.
- Обновления лаунчера подписаны отдельным ключом: секретная часть есть только у CI (`LAUNCHER_SIGNING_KEY`), открытая лежит в `keys/launcher.key` и вшита в лаунчер. Через взломанный сервер или зеркало свой exe не подсунуть.
- Плагин Tauri (`tauri-plugin-updater`), `updater.json` на GitHub и секреты `TAURI_SIGNING_*` из первой версии PR #5 убираются.
