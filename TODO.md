## Обновление лаунчера

### 1.3.0: плагин Tauri, как уже написано в PR #5

1. Ручной запуск сборки на `main` с галочкой release собирает установщики, подписывает их ключом самообновления (`TAURI_SIGNING_*`) и выпускает GitHub Release с `updater.json`.
2. Лаунчер при старте и раз в 15 минут читает `updater.json` из последнего релиза того репозитория, который его собрал. Если версия новее, в шапке появляется «Вышел Elite Launcher vX — Обновить».
3. По кнопке скачивает установщик целиком (Windows около 2 МБ, Linux AppImage около 80 МБ) и проверяет подпись открытым ключом, вшитым в лаунчер.
4. Windows: лаунчер закрывается, установщик без вопросов ставит новую версию поверх (видно его окно с полоской) и запускает её. Linux: AppImage подменяется. macOS: подменяется `.app`.
5. Без кнопки ничего не ставится. Портативный zip и сборки без ключа получают только ссылку `launcher_update` из `launcher.json`. Лаунчеры 1.2.x переходят на 1.3.0 вручную.

### Потом: свой движок вместо плагина

Тот же механизм, что у Elite: CI публикует лаунчер как версию (манифест и куски) на наш сервер, лаунчер по кнопке докачивает только изменённые куски, переименовывает свой exe в `*.old`, кладёт новый и перезапускается. Без окна установщика и без GitHub, портативный zip тоже обновляется, AppImage не качается целиком. Новости (заметки релизов) тогда тоже берутся с нашего сервера, а не из GitHub API. Нужен свой ключ подписи (`LAUNCHER_SIGNING_KEY`) и ответ владельца, как папка загрузок попадает на зеркала.

### Сервер (у автора, рядом с `/stats/api` и `/ladder/api`)

| Фича | Приоритет | Реализовано | Заметки |
|---|---|---|---|
| **Вход через Steam** | P1 | — | «Sign in through Steam» (OpenID): сервер получает проверенный SteamID, пароль Steam никто не видит. Сессия для лаунчера. Ник и аватар — Steam Web API (`GetPlayerSummaries`, бесплатный ключ на сервере). Вход нужен для чата, онлайна и друзей; без входа лаунчер работает как сейчас. |
| **Друзья из Steam** | P2 | — | Steam Web API `GetFriendList`: работает, только если у игрока открыт список друзей в настройках приватности Steam. Друзья наверху списка онлайн с пометкой. |
| **Онлайн и где кто** | P1 | — | Открыл лаунчер → живое соединение с сервером → игрок «в лаунчере». Нормальное закрытие → лаунчер говорит серверу «пока», игрок пропадает сразу. Падение, выключение ПК, пропал интернет → сервер держит игрока онлайн, только пока тот отзывается (раз в 30–60 с); 2 минуты тишины → офлайн. Статус: в лаунчере / в поиске (режим, рейтинг) / в матче (режим, карта). Поиск и матчи — от сервера автоматча (`rts.fintebtc.de/ladder`). Лаунчер закрыт, а игрок в игре → «в игре» сообщает DLL в игре (LobbyStats уже ходит на сервер). Точнее всего — со сворачиванием в трей. |
| **Счётчики «в игре / с Elite / в поиске»** | P1 | — | Всего в игре: публичный Steam Web API `GetNumberOfCurrentPlayers` (appid 56400), без ключа и без нашего сервера, но ванилла, Elite и кампания вместе.
